MONKEY TURN V SETTING PRO - iPhone PWA

Files:
- index.html: app
- manifest.json: home-screen app metadata
- sw.js: offline cache
- icon-192.png / icon-512.png: app icons

To install on iPhone:
1. Upload the contents of this folder to an HTTPS web host (for example GitHub Pages).
2. Open the published HTTPS URL in Safari.
3. Tap Share -> Add to Home Screen.
4. Enable "Open as Web App" if that option appears, then tap Add.

Note: iOS home-screen installation requires the app to be served over HTTPS. This ZIP is the deployable app package; it is not itself an App Store installation file.
